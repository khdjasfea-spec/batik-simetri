Berikut ialah tatacara ringkas untuk bermain **Batik Symmetry Agent | Markas Nexus**:

1. **Daftar Nama Kod Ejen:** Masukkan nama panggilan anda pada halaman permulaan dan ikuti 3 babak pengenalan ringkas masuk ke Markas Nexus.
2. **Pilih Avatar Ejen:** Pergi ke menu **Profil Ejen** untuk memilih karakter kegemaran anda (**Ejen Arif**, **Ejen Aira**, atau **Ejen Baraq**).
3. **Ulang Kaji & Berlatih (Pilihan):** Buka **Pusat Ilmu** untuk membaca nota bergambar serta mencuba **Makmal Latihan** melukis paksi simetri pada bentuk asas dan batik.
4. **Selesaikan 3 Misi (9 Tahap):** Masuk ke **Peta Misi** dan lengkapkan semua cabaran mengikut tahap:
* **Misi 01 (Rookie):** Lukis paksi simetri bentuk asas & kenal pasti corak bersimetri.
* **Misi 02 (Operative):** Seret jari/tetikus pada gambar batik untuk melukis garis paksi simetri menegak, melintang, atau pepenjuru.
* **Misi 03 (Elite):** Klik petak grid di sebelah kanan untuk melengkapkan pantulan cermin corak batik.


5. **Gunakan Bantuan N.O.V.A.:** Tekan butang **Imbasan N.O.V.A.** atau ikon robot terapung di penjuru bawah kanan untuk mendapatkan petunjuk tanpa mengurangkan markah.
6. **Kumpul Markah & Sijil:** Jawab dengan tepat untuk mengekalkan **3 tenaga hati**, naik pangkat sehingga **Ejen Master**, dan cetak **Sijil Ejen NEXUS** di menu **Laporan & Sijil**.
